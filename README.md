# 📈 Binance Trading Bot

**Binance Trading Bot** — це автоматизований бот для торгівлі криптовалютами на Binance. Він використовує API біржі Binance для виконання ордерів, аналізу ринку та автоматизації торгових стратегій.

## 🚀 Основні можливості
- 📊 **Автоматичний трейдинг** на Binance.
- 🔎 **Аналіз ринкових даних** та прийняття рішень.
- 🔧 **Гнучкі налаштування** торгових стратегій (`config.py`).
- 🛠 **Підключення до бази даних** для збереження історичних даних.

---

## ⚙ Встановлення
### 1️⃣ Клонування репозиторію:
```bash
git clone https://github.com/ТВІЙ_ГІТХАБ/binance_bot.git
cd binance_bot
```

### 2️⃣ Встановлення залежностей:
```bash
pip install -r requirements.txt
```

### 3️⃣ Налаштування змінних середовища:
Створи файл `.env` або онови `config.py` та додай:
```
API_KEY=твій_ключ_Binance
API_SECRET=твій_секретний_ключ_Binance
TRADE_PAIR=BTCUSDT
TRADE_AMOUNT=0.01
```

---

## ▶ Запуск бота
```bash
python bot.py
```

---

## 📜 Основні файли
- `bot.py` — Головний скрипт трейдингового бота.
- `config.py` — Файл конфігурації бота.
- `crypto_data.db` — Локальна база даних (SQLite) для збереження історії угод.
- `utils.py` — Допоміжні функції.
- `requirements.txt` — Список необхідних бібліотек.

---

## 🛠 Технології
- **Python** 3.10+
- **Binance API** (автоматизація торгівлі)
- **SQLite** (збереження даних)
- **Pandas, NumPy** (аналіз ринку)
